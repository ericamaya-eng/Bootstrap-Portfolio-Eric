Funny Reanimation

For my final project, I wanted to make something silly and lighthearted for an easy laugh, but I also wanted it to culminate with everything that I enjoyed learning and learning about during this semester’s DMA intro class. Firstly, if I wanted to animate the clip I wanted, I downloaded a reference video, so I used a site, you know, one of those kinds of sites, and I downloaded a clip from Puss in Boots 2. Secondly, in order to animate, I had to find a model in which I could recreate the scene with. Initially, I was going to make my own model, but I’m not experienced enough with Blender, so I decided against it and wanted to use a character that I had an assignment about earlier in the semester, so I decided to use a Sonic model.

Initially, I wanted to use the model I 3D printed of Sonic earlier in the semester, but I couldn’t find a good rigged version, so then I tried another one, but that one had rigging issues, and then I tried another one, but that one wasn’t rigged like it was supposed to be at all, and then I found one that worked and was simple enough to use without knowing too much about rigs. So I got to animating. First, I started by inserting my reference footage inside of Blender and blocking out the movement by leaving the model in a T-pose and just matching the basic movement, and then I cleaned up the animation by matching the poses with the poses of the reference footage, and that looked pretty good, so I decided to move on to adding some props such as the monkey cube and the glitched monkey from our glitched images assignment I worked so hard on so long ago.

I also added a colorful background that I sourced from a favorite video game of mine. In order to make the cube, the glitched image, and the background really pop, I decided to make their materials super basic, which is a skill I picked up a long time ago when I was using Blender on my own before I came to school here. After I was done with that, I realized my animation needed lighting, so I decided to add a sun-type light that matched up with the sun in the background I added, but when I did that, the lighting wasn’t very appealing, so I decided to add an additional spotlight that lit the character specifically, like in a stage play or an old movie.

Now that I was done with the prettying up of everything, it was time to export it into an MP4. I had to look up how to specifically export it into an MP4, and it took some time to figure it out, but I got the hang of it, so the video got exported. The video didn’t have the sound from the original video I referenced, so I decided to pull up Shotcut, I’m not familiar with Premiere Pro yet, to add the proper sound and edit the audio so it was less aggressive. All in all, it was a really fun process that combined the Blender lessons, the glitched images lessons, and the slight audio lessons, and I look forward to using these awesome skills in the future.
